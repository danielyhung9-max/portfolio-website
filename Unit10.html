Unit 10: Database Development

In this unit I learnt how to:

  1. Understand how to solve a mystery
  2. Understand how to create form and queries
  3. Understand how to write an evaluation

    4. What did you enjoy about this unit?

    I like how we create form and queries

    What improvements would you make if you did the unit again?

    I would like to improve on how i create my relationship

    In this unit, I had to make a database in Microsoft Access. My task was to make a database for a GP. My database had to include queries, reports relationships and multiple forms that will allow easy navigation. The database also had to be protected by a password.




    Then I had to test and review it, saying why it would fit its purpose. In another assignment for this unit, I had to explain different tools and techniques used in creating databases. To do that, I had to use two databases used for different purposes as examples.

    What did you enjoy about this unit?

    In this unit, I enjoyed the process of creating the database because I had the opportunity to learn how they are made and how the data in them is structured.

    What improvements would you make if you did the unit again?

    Next time, I would make the forms look better and I would add more functionality to them.
